Tentang MoldGuard

Aplikasi bantu pemeriksaan awal indikasi jamur pada permukaan bangunan melalui foto.

Cara Kerja

{{ icon('activity', 18) }}
  1. 1 Ambil atau unggah fotoGunakan kamera atau pilih gambar dari galeri. Format yang didukung: JPG, PNG, WEBP, BMP hingga 16MB.
  2. 2 Model menandai areaYOLOv8 mencari area yang menyerupai jamur, lalu classifier MobileNetV2 memperkirakan spesies pada area tersebut.
  3. 3 Lihat dan simpan hasilHasil menampilkan anotasi, keyakinan model, dan rekomendasi. Simpan ke riwayat perangkat bila diperlukan.

Batasan yang Perlu Diketahui

{{ icon('alert-triangle', 18) }}
  • Hasil AI adalah indikasi visual, bukan diagnosis medis atau hasil uji laboratorium.
  • Keyakinan model menunjukkan performa deteksi objek, bukan tingkat bahaya bagi kesehatan.
  • Classifier hanya mengenali lima jenis jamur dari dataset pelatihan. Spesies di luar itu tidak dapat dipastikan.
  • Foto gelap, blur, atau sudut yang sulit dapat membuat area terlewat. Ulangi dengan pencahayaan lebih baik.
  • Tidak ada sensor kualitas udara atau kelembapan pada versi ini, sehingga MoldGuard tidak menampilkan skor tersebut.

Bantuan & Pertanyaan Umum

Hal yang paling sering ditanyakan tentang MoldGuard.

{{ icon('help', 18) }}
Apakah hasil MoldGuard bisa dipakai sebagai diagnosis?

Tidak. Hasil berupa indikasi visual dari model AI. Untuk keluhan kesehatan atau kerusakan bangunan yang serius, konsultasikan dengan tenaga kesehatan atau ahli bangunan.

Di mana riwayat pemeriksaan saya disimpan?

Riwayat, pengingat, profil, dan preferensi disimpan di localStorage browser pada perangkat ini. Data tidak tersinkron ke perangkat lain dan akan hilang jika data browser dibersihkan.

Apakah foto saya disimpan di server?

Foto dikirim ke server hanya saat Anda menekan “Mulai Analisis” untuk diproses model. Server tidak menyimpan foto secara permanen. Thumbnail hasil disimpan di perangkat Anda jika Anda menekan “Simpan Hasil”.

Mengapa kamera tidak bisa dibuka?

Kamera memerlukan izin browser dan koneksi aman (HTTPS atau localhost). Jika izin ditolak atau perangkat tidak memiliki kamera, gunakan tab Galeri untuk mengunggah foto.

Apakah aplikasi mengirim notifikasi saat ditutup?

Belum. Pengingat hanya tampil di dalam aplikasi. MoldGuard tidak memiliki mekanisme push atau layanan latar belakang pada versi ini.

Seberapa akurat perkiraan spesies jamur?

Classifier dilatih pada lima jenis jamur dan hanya memberi perkiraan pada area yang ditandai. Hasil ini bukan identifikasi laboratorium dan tidak boleh dipakai untuk menentukan penanganan medis.

Bagaimana cara menghapus seluruh data saya?

Buka Pengaturan → Hapus Data Saya. Tindakan tersebut menghapus riwayat, pengingat, profil, dan preferensi dari perangkat ini.

Kebijakan Privasi

Ringkasan cara MoldGuard menangani data.

{{ icon('shield', 18) }}
Data yang disimpan di perangkat
  • Nama tampilan profil yang Anda isi.
  • Riwayat pemeriksaan beserta thumbnail foto dan catatan lokasi.
  • Pengingat perawatan dan preferensi tampilan.
Data yang dikirim ke server
  • Foto yang Anda pilih, hanya saat analisis dijalankan.
  • Hasil analisis dikembalikan ke browser untuk ditampilkan.
  • Foto tidak disimpan permanen oleh server aplikasi.
Yang tidak dilakukan
  • Tidak ada akun, login, atau pelacakan lintas situs.
  • Tidak ada iklan atau penjualan data.
  • Tidak ada sinkronisasi data ke cloud.
Kendali Anda
  • Hapus pemeriksaan satu per satu dari halaman Riwayat.
  • Hapus seluruh data dari halaman Pengaturan.
  • Hapus data situs melalui pengaturan browser kapan saja.

{{ icon('info', 14) }} Kebijakan ini menjelaskan perilaku aplikasi versi ini. Jika integrasi akun atau sensor ditambahkan, halaman ini perlu diperbarui.
