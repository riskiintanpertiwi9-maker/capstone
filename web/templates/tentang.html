Tentang MoldGuard

Sistem deteksi dan klasifikasi jamur dinding berbasis hybrid deep learning.

🎓 Judul Proyek Capstone

Judul Resmi
"Implementasi Metode Hybrid Deep Learning Menggunakan YOLOv8 dan MobileNetV2 untuk Deteksi dan Klasifikasi Jamur Dinding Berbasis Citra Digital"

Proyek ini merupakan proyek capstone Informatika yang mengembangkan sistem pemeriksaan visual berbasis kecerdasan buatan untuk membantu pengguna mengenali indikasi jamur pada dinding bangunan.

🎯 Tujuan Pengembangan

MoldGuard dikembangkan untuk membantu masyarakat umum dalam melakukan pemeriksaan awal kondisi dinding menggunakan foto digital. Sistem ini bukan pengganti pemeriksaan profesional, melainkan alat bantu yang dapat digunakan secara mandiri menggunakan ponsel.

Secara spesifik, MoldGuard bertujuan untuk:

  • ✅Membantu pengguna memeriksa foto dinding untuk menemukan indikasi visual jamur.
  • ✅Mendeteksi lokasi area yang diduga berjamur menggunakan YOLOv8 (object detection).
  • ✅Mengklasifikasikan kondisi gambar menggunakan MobileNetV2 (image classification).
  • ✅Menyajikan panduan penanganan dan pencegahan langsung pada halaman hasil pemeriksaan.
  • ✅Membantu pengguna memahami kapan kondisi dapat ditangani sendiri dan kapan memerlukan bantuan profesional.

⚙️ Teknologi yang Digunakan

MoldGuard menggunakan pendekatan hybrid deep learning yang menggabungkan dua model dengan peran yang saling melengkapi dalam satu pipeline analisis.

🎯 YOLOv8 (Ultralytics)
Digunakan untuk object detection — mendeteksi lokasi dan menandai area spesifik pada gambar yang memiliki pola sesuai kelas yang dilatih (mold, clean, suspected). Menghasilkan bounding box dan skor keyakinan per deteksi.
📱 MobileNetV2 (Keras)
Digunakan untuk image classification — mengklasifikasikan keseluruhan gambar ke dalam kelas yang telah dilatih. MobileNetV2 dipilih karena ringan dan efisien untuk inferensi pada perangkat dengan sumber daya terbatas.
🐍 Flask (Python)
Framework web backend untuk menangani routing, pemrosesan gambar, dan komunikasi antara antarmuka pengguna dengan model AI.
🌐 HTML / CSS / JavaScript
Antarmuka pengguna dibangun dengan teknologi web standar tanpa framework frontend tambahan agar ringan dan kompatibel dengan berbagai perangkat.
🖼️ OpenCV
Digunakan untuk pemrosesan gambar di sisi server: membaca, mengkonversi format, dan menghasilkan gambar anotasi dari hasil deteksi YOLO.
📊 scikit-learn
Digunakan dalam pipeline evaluasi model untuk menghitung metrik akurasi, F1-score, precision, recall, dan confusion matrix.

🔄 Alur Kerja Sistem

Berikut adalah alur kerja dari input foto hingga hasil prediksi yang ditampilkan kepada pengguna.

1
Input Gambar
Pengguna mengambil foto dinding langsung menggunakan kamera HP atau mengunggah file gambar dari galeri maupun komputer.
2
Validasi & Pengiriman
File gambar divalidasi (format, ukuran) di sisi frontend sebelum dikirim ke server melalui endpoint POST /predict.
3
Deteksi YOLOv8
Model YOLOv8 menjalankan inferensi pada gambar dan mengidentifikasi lokasi area yang sesuai dengan kelas yang telah dilatih, beserta skor keyakinan dan koordinat bounding box.
4
Klasifikasi MobileNetV2
Gambar yang sama diproses secara paralel oleh MobileNetV2 untuk menghasilkan distribusi probabilitas kelas, melengkapi hasil deteksi YOLO.
5
Penentuan Status
Sistem menggabungkan hasil kedua model untuk menentukan status pemeriksaan: Indikasi Terdeteksi, Tidak Ditemukan Indikasi, atau Hasil Tidak Meyakinkan.
6
Tampilan Hasil
Halaman hasil menampilkan foto asli, foto dengan anotasi, hasil per model, penjelasan, panduan penanganan yang disesuaikan dengan status, tips pencegahan, dan peringatan keselamatan — seluruhnya dalam satu halaman.

⚠️ Batasan Sistem

MoldGuard adalah alat bantu pemeriksaan visual berbasis citra. Penting untuk memahami keterbatasan sistem ini sebelum menggunakannya:

🔍 Model hanya dapat menganalisis apa yang terlihat pada gambar. Jamur di balik dinding, di dalam plafon, atau di area yang tidak terfoto tidak dapat dideteksi.
📷 Kualitas prediksi sangat dipengaruhi oleh kualitas gambar: pencahayaan, ketajaman fokus, sudut pengambilan, dan resolusi foto.
🧬 Model tidak dapat mengidentifikasi spesies jamur secara pasti. Klasifikasi yang diberikan hanya berdasarkan pola visual yang dipelajari dari dataset pelatihan.
🏥 Hasil pemeriksaan ini bukan diagnosis medis atau bangunan yang sah. Untuk kondisi yang serius atau memengaruhi kesehatan, konsultasikan dengan profesional terkait.
📊 Performa model bergantung pada kualitas dan cakupan dataset pelatihan. Model mungkin kurang akurat untuk kondisi dinding yang berbeda dari data pelatihan.
